# VaXease – Static Website

Static multi-page website for VaXease vaccination compliance platform. No build step, no React—pure HTML, CSS, and JavaScript.

## Structure

```
VaXease-website/
├── index.html      # Home
├── login.html      # Login (redirects to HR / Parent / Nurse by role)
├── contact.html    # Contact Us
├── hr.html         # HR Dashboard
├── parent.html     # Parent Portal
├── nurse.html      # Nurse Interface
├── css/styles.css
├── js/theme.js
├── js/tabs.js
└── favicon.svg
```

## Run locally

Open `index.html` in a browser or use a local server:

```
npx serve .
# or
python -m http.server 8000
```
